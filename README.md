# 🔢 CoDeCo – Huffman Coding Visualizer
CoDeCo is a web-based visualization tool for understanding the Huffman coding and decoding algorithms. It provides an interactive way to see how data compression works step by step.

## 🚀 Features
- ✅ Visual representation of the Huffman tree generation
- ✅ Step-by-step encoding and decoding process
- ✅ User input support – test with custom text
- ✅ Educational tool for learning compression algorithms

## 🔧 Technologies Used
- JavaScript (ES6+)
- HTML5 & CSS3

##  📌 Notes
This project was built to help students and developers better understand Huffman coding through intuitive and dynamic visualizations.
